Choose which AI provider generates your comments and posts, and store its API key in your Mac's Keychain.

Stored LinkedIn Credential

Checks that the password for the selected profile is stored where it should be and can be read back. It does not contact LinkedIn and does not sign in, so it cannot tell you the credential is correct — only logging in can. The password is never shown here.

Generation Provider

Applies to the profile selected at the top of the page. Takes effect on the next generation run. Changing this does not touch your persona, tone, or voice.

Test Connection sends one small prompt to check the endpoint, the model name, and whether this model keeps your comments varied. It is the only button here that spends money, at most two calls, logged to api_usage.jsonl.

API Keys

Keys are stored in your Mac's Keychain, never in a file in this project. Once saved, a key can never be read back here: you will only ever see its last four characters. To replace one, paste a new key over it.
